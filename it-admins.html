Managed deployment for IT admins

Dynamic Dynamo Kit is published as a Microsoft Store MSIX app (Store ID 9PPPSZWZ87WM, publisher Mykal2709). Deploy the Store app directly; do not download and repackage the MSIX.

Deploy with Microsoft Intune (recommended)

  1. In the Microsoft Intune admin center, go to Apps → All apps → Create.
  2. Select Microsoft Store app (new).
  3. Search for Dynamic Dynamo Kit (Store ID 9PPPSZWZ87WM) and select the listing published by Mykal2709. Confirm the app identity before adding it.
  4. Complete App information, review the app details, and configure any available install-behavior options.
  5. Under Assignments, target a small pilot group first:
    • Available for enrolled devices lets users install it from Company Portal.
    • Required installs it automatically on targeted devices.
  6. Select Review + create.
  7. Check installation status in Intune, confirm the app launches, then expand the assignment.
Updates: Intune keeps Store apps current automatically. You do not upload a new package for each release.

Install with winget

For scripted installs, or environments that use winget instead of Intune:

winget install --id 9PPPSZWZ87WM --source msstore --accept-package-agreements --accept-source-agreements
  • The two --accept-* flags prevent agreement prompts during unattended runs.
  • The msstore source must be enabled (check with winget source list). Some organizations disable it by policy.
  • winget installs per user. Run it in the target user's context, not as SYSTEM.
  • Updates arrive through the Store or with winget upgrade --id 9PPPSZWZ87WM.

Requirements and rollout checks

  • x64 Windows 10 version 2004 (build 19041) or later, including Windows 11.
  • Microsoft documents that Store app deployment through Intune requires the Intune Management Extension, at least two processor cores, and access to Microsoft Store and app content endpoints.
  • Check Store policies, proxy and firewall rules, device enrollment, and Windows version before a broad assignment. Pilot on a representative managed device.
  • The Store listing is currently available in the United States. Contact support before planning deployment in other countries.

If Store delivery is blocked

No separately signed enterprise MSIX is offered at this time. If your organization cannot use the Microsoft Store or winget's msstore source, contact support to discuss options.

Licensing

The Free tier is included with every install. Pro licenses are purchased through Lemon Squeezy, not Microsoft Store, and are activated per device in Settings. Monthly and annual Pro plans allow two device activations; the Team plan allows ten. See the Quick start for details.
