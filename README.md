# Dynamic Dynamo Kit

Dynamic Dynamo Kit (DDK) is a native Windows administration toolkit for
Dynamics 365 and Microsoft Dataverse. Review user and team access, audit security
roles, investigate duplicate records, and preview supported changes with What-If.

**[Get DDK from Microsoft Store](https://apps.microsoft.com/detail/9PPPSZWZ87WM)** |
**[Visit the documentation website](https://mykal2709.github.io/dynamic-dynamo-kit-legal/)**

The Free tier is included. Pro is an optional upgrade sold separately.
The current Store package is x64 and requires Windows 10 version 2004
(build 19041) or later, including Windows 11.

## Need help?

Read the [support guide](https://mykal2709.github.io/dynamic-dynamo-kit-legal/support.html),
then [open a support issue](https://github.com/mykal2709/dynamic-dynamo-kit-legal/issues/new).
A GitHub account is required to submit an issue.
You can also [view existing requests](https://github.com/mykal2709/dynamic-dynamo-kit-legal/issues).

Include:

- App and Windows versions.
- The affected tab or control and the complete error text, with sensitive details removed.
- Sanitized steps to reproduce the problem.
- Authentication mode, without credentials.
- Whether What-If was enabled.

**Issues are public.** Never post license keys, passwords, client secrets,
access tokens, certificate passwords, customer records, tenant-confidential
information, or unredacted logs and screenshots.

DDK is independently built and supported by one developer outside regular working
hours. Support is best effort; response times vary and immediate replies are not
guaranteed. Installation and licensing problems are prioritized. Purchasing Pro
does not create a service-level agreement.
