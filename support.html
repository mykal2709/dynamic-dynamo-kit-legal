Help and issue reporting

Support

Dynamic Dynamo Kit is independently built and supported by one developer outside regular working hours.

Response expectations: support is best effort, response times vary, and immediate replies are not guaranteed. Licensing and installation problems are prioritized. Purchasing Pro does not create an SLA.

Before reporting a problem

  1. Confirm you are running version 2.3.3 or later.
  2. Retry with What-If enabled if the workflow supports changes.
  3. Use Settings > Test connection for sign-in or environment errors.
  4. Check the connection troubleshooting table.

What to include

  • App and Windows versions
  • Affected tab and exact control
  • The complete error text
  • Authentication mode, without credentials
  • Sanitized steps that reproduce the problem
  • Whether What-If was enabled
Never share a Pro license key, client secret, access token, certificate password, customer data, tenant-confidential information, or an unredacted screenshot.

Open a support issue on GitHub

Support issues are public. Sanitize all logs and screenshots before attaching them.
