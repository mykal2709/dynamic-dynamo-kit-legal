Quick start

Go from installation to a verified, read-only access report. Plan about ten minutes if you already know your Dataverse environment URL.

Safest first session: connect to a sandbox, leave What-If Mode on, and start with a report before trying any operation that changes data.

  1. Install from Microsoft Store

    Open the Dynamic Dynamo Kit Store listing, select Get or Install, then launch the app. The Free tier is included.

  2. Add and connect an environment

    On first launch, open Settings if the setup prompt is not already visible. Add a recognizable environment name and its full URL, for example https://yourorg.crm.dynamics.com. Do not include /main.aspx.

    Choose an authentication mode:

    • Interactive/MFA for normal user sign-in and Conditional Access prompts.
    • Service Principal for an unattended app registration with a client secret.
    • Certificate for an app registration configured with a certificate.

    Select Test connection, save Settings, then use the main Connect button. On-premises deployments can use the app's supported IFD/AD connection options when configured for that environment.

  3. Confirm the account has enough access

    The toolkit uses the permissions of the account you connect. Read-only reports need read privileges for the records they inspect. Role, team, user, import, merge, or ownership changes need the matching Dataverse administrative privileges.

    If sign-in succeeds but the app returns 401 or 403, confirm the account has a Dataverse security role and an appropriate Microsoft license or application-user record.

  4. Turn on What-If Mode

    Enable the global What-If Mode before exploring write workflows. Supported changes are previewed instead of written. Read each preview and confirmation; What-If reduces risk but does not replace a sandbox, a backup, or review.

  5. Run a safe first report

    Open Users > User Access > Roles. Choose the environment, find a user, and select Load roles. Review the role, source, and business-unit columns. This is a useful connection and permission check without changing Dataverse.

    You can also try Org > Role Reports > Users by Role and export the report for review.

  6. Evaluate the Pro trial

    The app labels its current tier as Free, Pro (Trial), or Pro. Pro unlocks bulk import, promotion, governance, onboarding, offboarding, mass reassign, Find & Merge, insights, and licensing workflows.

    To purchase, use Buy a Pro license in Settings. Checkout is handled by Lemon Squeezy, not Microsoft Store. Enter the issued key and select Activate. Monthly and annual Pro plans allow two device activations; Team allows ten.

Connection troubleshooting

ProblemWhat to check
MFA or Conditional Access prompt failsUse Interactive/MFA. For unattended work, use a properly configured service principal or certificate.
Environment not foundCopy the Environment URL from Power Platform admin center; remove trailing paths.
401 UnauthorizedAssign the account at least one Dataverse security role.
403 ForbiddenCheck the user's license or the service principal's application-user record.
Timeout or DNS errorCheck VPN, proxy, firewall, and whether the URL opens from the same computer.
Pro features lockedOpen Settings and review the tier, trial, key, network access, and license status.
